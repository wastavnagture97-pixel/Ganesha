# 🕉️ Lord Ganesha Particle Art Visualizer

A visually captivating real-time particle animation and art reconstruction of **Lord Ganesha** with devotional background audio, built using Python, Pygame, and OpenCV.

## ✨ Features

- **Devotional Audio Sync**: Plays "Gajanana" background audio on loop with mute/unmute toggle.
- **Dynamic Particle Assembly**: Ganesha image reconstruction using rising/falling particle physics.
- **Edge Detection & Gold Outlining**: Utilizes OpenCV Canny edge detection for celestial outlines.
- **Pulsing Diyas / Flame Glows**: Smooth mathematical pulsing light effects on traditional lamps.
- **Glossy Pastel Aura & Ambient Rain**: Floating flowers and glittering particle effects.
- **Full Display Adaptation**: Dynamically adjusts to screen dimensions.
- **Secret Developer Info Modal**: Press `C`, `I`, or `H` anytime to open the developer credit card.

## 🚀 Getting Started

### Prerequisites

Make sure you have Python installed, then install the dependencies:

```bash
pip install pygame opencv-python numpy
```

### Running the Visualizer

Run the script from your terminal:

```bash
python ganesh_visualizer.py
```

### ⌨️ Controls
- **`M`**: Mute / Unmute Background Music
- **`C` / `I` / `H`**: Toggle Secret Developer & Project Credits Card
- **Click Watermark**: Opens the Secret Credits Card
- **`ESC`**: Close Info Card / Exit Visualizer
